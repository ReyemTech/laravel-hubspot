## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| composer.json → installed vendor tree | A declared constraint decides what code a consumer executes |
| `src/` imports → declared requires | An undeclared import is code that runs only because someone else's manifest happened to supply it |
| CI gate → merge | A gate that cannot fire is a merge with no review |
