Ship HOOK-02's runtime half: `php artisan hubspot:webhooks:sync` reconciling an explicit
desired-state subscription list against a legacy public app's portal state — create and update only,
extras reported and never removed, with `--dry-run` for review and CI.

explicitly and instructs that they be derived here rather than invented at roadmap level. This plan
derives them from D-10 through D-12 and D-16, and pins each one with a test.

object, the app-model enum, the reconciliation command, and the credential handling D-16 fixes.

before the subscription Gateway task because the app model and credential class were unresolved.

public apps only, app id plus Developer API key, no Service Keys, no Webhook Journal API. The door
is already walked through, so no checkpoint re-asks it.
