<objective>
Complete HOOK-02 by shipping D-16's two non-API app-model paths: legacy private apps get validated,
rendered manual setup instructions, and current project-based apps get an exportable webhook
component. Neither path issues a single HubSpot request.

Purpose: D-16 makes webhook receipt work for every HubSpot app model but makes runtime
reconciliation available for only one of them. A package that shipped only the legacy-public branch
would leave the two other models with a command that either fails or, worse, silently does nothing —
and the model HubSpot itself calls current is one of them.

Output: The manual-instructions renderer, the project component renderer, the remaining two branches
of the command's app-model match, and the missing-target-URL error both paths need.
</objective>
