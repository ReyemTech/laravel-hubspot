<objective>

travels through the route macro, Gateway-owned SDK verification, normalization, queued job, and
generic Laravel event. Expand that slice to all batch and failure statuses per D-13, D-14, and D-15.

event, provider wiring, and focused security/HTTP tests.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HubSpot/client -> webhook route | Untrusted headers, URI, and body enter the package. |
| Webhooks -> Gateway | Raw signature inputs cross into the sole SDK-owning layer. |
| HTTP process -> queue | Validated items become durable asynchronous work. |
| Plan -> build gates | A rule this plan widens is the boundary later phases are checked against. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Spoofing | WebhookController | critical | mitigate | Fail closed with SDK signature verification and 300-second tolerance before parsing or dispatch. |
| T-05-02 | Tampering | Raw URI construction | high | mitigate | Preserve REQUEST_URI byte ordering and pin unsorted-query behavior in an HTTP test. |
| T-05-03 | Information Disclosure | Failure logging | high | mitigate | Log fixed diagnostic fields only; tests reject body, signature, and secret disclosure. |
| T-05-04 | Denial of Service | Batch handoff | medium | mitigate | Strictly validate list/items and return 500 whenever full queue handoff is not achieved. |
| T-05-05 | Elevation of Privilege | Enforcement bypass | high | mitigate | Default enforcement true and make bypass explicit, warning-bearing, and documented for local development only. |
| T-05-12 | Tampering | R4 allow-list | high | mitigate | The widening appends the framework namespace only; a committed fixture proves R4 still fails on an SDK import from Webhooks, and that guard is played in isolation so it cannot be satisfied by an unrelated violation. |
