## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| production process → receipt log | The recorder is called from real code paths; only the `isFaked()` gate keeps a production process from accumulating customers' behavioural data in memory. |
| test process → CI transcript | Assertion failure messages cross into a CI log that outlives the test run and is visible to anyone with repository access. |
| `Signals` → `Testing` | R5 forbids the dependency outright; the port is what makes the capability reachable without it. |
