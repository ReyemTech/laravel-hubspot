`reyemtech/laravel-hubspot` is a Laravel package for HubSpot CRM that covers every CRM object type
— contacts, companies, deals, products, line items, tickets, quotes, and custom objects — with
directional associations and inbound webhooks handled properly, which no other maintained package
in this ecosystem does.
